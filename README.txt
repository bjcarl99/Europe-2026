BARRY'S EUROPE GUIDE - STARTER

1. This folder is a working web-app prototype.
2. To test on a computer, host the folder with a simple web server. Location will only work on HTTPS or localhost.
3. To put it on an iPhone, publish the folder to a secure web host, open the link in Safari, then choose Share > Add to Home Screen.
4. Exact city dates are placeholders in data.js and can be updated once supplied.
5. The in-app live map uses OpenStreetMap to avoid requiring a paid Google Maps API key. Every place includes Google Maps search and walking-direction buttons.
6. The home-address pin should be removed before sharing the app publicly.
